Cohort-mix forecaster for GTA VI week-one trophy earn rates: per-trophy (ceiling, timescale) fit on the case's own history, power-law player growth, refresh-aware spread — 55 trophies, 5 quantiles each, deterministic Python 3.13 stdlib.

## Run it

```sh
python3 main.py
```

Reads each `<id>.in` case from `$MAKEFUN_INPUT_DIR` (default `/input`) and writes `<id>.out` forecasts to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
